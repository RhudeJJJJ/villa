# Existing upstream code licenses

The ScrollPrize/villa repository root contains an MIT license. Its `volume-cartographer` subproject contains a GPLv3 license. Both original texts are preserved separately as `LICENSE-ROOT-MIT.txt` and `LICENSE-VOLUME-CARTOGRAPHER-GPLv3.txt`.

`requested-resume-bounds.patch` modifies the existing volume-cartographer source. It does not relicense that source or remove existing notices. Any separate permissive license grant for newly authored additions or standalone helpers must be read as a grant for those additions, while the combined subproject code retains its existing license obligations.

The public real-data attribution and CC BY-NC terms are described separately in `DATA-ATTRIBUTION.md`; they do not assign the code license.
